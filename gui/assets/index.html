設定熱重載

      

        

          

            重新載入 .env / mcp.json
            

              Re-reads .env (typed re-assign), resets the LLM provider
              chain, restarts daemon services (scheduler / webhook /
              Telegram / ONVIF watches per their enable-conditions) and
              reconnects the MCP fleet. Deletion of an env var still
              needs a restart (dotenv never clears the process env).

        Central account sets shared by every service that needs a
        login (ONVIF cameras, …). Passwords are RECOMMENDED as env
        references (the store never holds the secret); plain
        passwords are stored base64-OBSCURED, not encrypted.
        Managed here, via MCP (cred_add / cred_list / …) and the CLI
        (python cli.py creds …).
